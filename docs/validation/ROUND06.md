# Round 06 — Optional rain deferred

Light rain is intentionally omitted from this release candidate. The approved priorities put water, journey stability and the sunset hero moment ahead of weather. The complete daylight-to-sunset experience has passed the continuous runtime audit; adding another rendering, wet-material and audio state would introduce a new QA surface without improving the core ride.

There is no rain control, dormant rain shader, weather menu or promise of an implemented rain feature in the release. Future work may explore it in an isolated branch after device review.
