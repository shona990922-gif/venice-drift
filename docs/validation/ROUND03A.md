# Journey expansion baseline

- Authored 499.727 m open canal, five sections and three distinct arch bridges.
- Distance-based 1.55 m/s cruise with gentle curve and bridge approach slowdown. Soft end fade returns to the start.
- Twelve independent Meshopt GLBs, forward preloading, geometry disposal behind the gondola, shared material pool and distant silhouettes.
- Real browser run at 1280 × 720: about 60 FPS, 9.3–9.9 ms GPU, 215–251 draw calls, 0.94–1.09 M rendered triangles (including auxiliary passes). Hardware/browser-specific observations, not mobile claims.
- Full-route swept gondola clearance and three actual bridge barrel meshes pass CPU ray tests; free-look remains independent.
- Day water, bridge approach and hero framing screenshots saved under local `qa/` (excluded from source control).
- The far church frontage, skyline termination, sunset sun placement and formal hero lighting remain the explicitly planned 03B/03C refinement work.

This checkpoint is the expanded journey skeleton, not a release candidate.
