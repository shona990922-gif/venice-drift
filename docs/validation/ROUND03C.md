# Scenery refinement

The five sections use intentionally varied facade widths, heights, floor spacing, three-to-five bay rhythms, shutter states and architectural motifs. Window lighting uses a per-opening baked seed, so whole windows light gradually and remain stable across GLB reloads.

Near-water dressing includes weathered mooring piles, hemp ties, parked gondolas, eroded coping, wall stains, plants and a restrained timber restaurant terrace. The hero basin now reveals a pediment church, dome and separate campanile, while a recessed piazza edge and terminal silhouettes enclose views beyond the finite route. The three bridges use distinct width, masonry and rail profiles.
