# Actual release captures

These are unretouched frames from the running WebGL application, not concept art or generated imagery.

- `day.png` — 1920×1080, passenger camera approaching the first bridge.
- `golden-hour.png` — 1920×1080, the residential turn as daylight warms.
- `sunset-hero.png` — 1920×1080, bridge, church, warm windows and reflected sunlight.
- `mobile-portrait.png` — Low tier, 390×844 viewport / 331×717 rendering buffer.
- `mobile-landscape.png` — Low tier, 844×390 viewport / 717×331 rendering buffer.
- `journey-sunset.mp4` — 12 seconds of real 1920×1080 automatic navigation and the app's own environmental audio; H.264/AAC. No microphone or desktop capture.

Viewport captures were made on an Apple M2 MacBook Air. They demonstrate responsive layout; they are not physical handset performance measurements. UI is omitted from canvas captures by design; the normal application has only Sound, Quality and Fullscreen controls.
